# PolyU Report LaTeX Template

A reusable LaTeX template for PolyU-style research seminar reports. It provides a structured cover page, editable course and student placeholders, and a report outline for technical reflection.

> This is an unofficial community template. Always check your course or department's latest submission requirements before use.

## Features

- Course-agnostic cover-page fields
- PolyU-branded cover page using the bundled `Logo.jpg`
- Editable fields for the course, student, department, seminar and submission date
- Structured sections for introduction, seminar content, technical reflection, social impact and conclusion
- Generic PDF metadata with no embedded author details

## Quick start

1. Download or clone this repository.
2. Keep `Logo.jpg` in the same directory as `PolyU_Report_LaTeX_Template.tex`.
3. Edit the fields near the top of the `.tex` file, including `\coursecode`, `\coursename`, `\studentname`, `\studentid`, `\departmentname`, `\seminartitle`, `\speakerinfo`, and `\seminardate`.
4. Replace the gray placeholder text and compile with pdfLaTeX or another LaTeX workflow that supports the included packages.

## Notes

- The default content is intended for research seminar reports and can be adapted to similar report assignments.
- The template intentionally leaves personal fields as placeholders. Do not commit completed reports containing personal or sensitive information.
